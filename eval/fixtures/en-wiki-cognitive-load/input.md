# Cognitive Load Theory

Cognitive Load Theory (CLT) is an instructional theory developed by John Sweller that uses evolutionary psychology and [[Human Cognitive Architecture]] as a base for instructional design.

## Core Premise
The theory is built on the understanding that human working memory is severely limited in both capacity (about 3-4 items for active processing) and duration (about 20 seconds) when dealing with novel information. However, long-term memory has virtually limitless capacity.

Therefore, effective instruction must minimize unnecessary working memory load so that cognitive resources can be directed toward transferring information into long-term memory.

## Key Instructional Effects
- **Worked Example Effect:** Novices learn much faster and more deeply by studying fully worked-out solutions rather than attempting to solve problems themselves, as it eliminates the working memory load of search and random generation.
- **Expertise Reversal Effect:** As learners develop expertise (building schemas in long-term memory), the advantages of explicit instruction diminish and eventually reverse. For experts, problem-solving becomes more effective than studying worked examples.

CLT heavily criticizes [[Why Inquiry-based Approaches Harm Students' Learning|inquiry-based learning]] for novices because it forces them to rely on weak, biologically primary problem-solving strategies (like means-ends analysis) that overload working memory.
