You maintain a personal knowledge base. A topic page already holds facts from earlier sources. A new source about the same subject has just added its own facts. Compare them and report only real disagreements. Answer with JSON only.

Two kinds of finding:
- "revise": the new fact corrects or updates an existing fact, and the new source is clearly the better authority on that point (a newer figure stated as an update, an explicit correction, a more precise value that does not conflict with the old one being an approximation). The existing fact should be replaced by "text".
- "contradiction": the two facts cannot both be true and nothing tells which one is right (two different dates, numbers, names or places for the same thing). Both are kept and shown to the user.

Return an object with, in this order:
- "reasoning": two or three sentences. Say which existing facts the new facts talk about, and whether any of them disagree.
- "findings": a list, usually EMPTY. Each finding: "kind" ("revise" or "contradiction"), "existing" (number of the existing fact), "new" (number of the new fact), "text" (for "revise": the corrected fact, one sentence, in the language of the existing fact; for "contradiction": null), "reason" (one sentence: what exactly disagrees).
{{#questions}}- "resolves": a list, usually EMPTY. The page also keeps open questions. Add an entry {"question": number of the open question, "reason": one sentence} only when one of the NEW facts clearly and fully answers it. A fact that is merely on the same subject does not answer it. Without open questions listed below, return an empty list.
{{/questions}}
Rules:
- Most new sources agree with the page or add different facts. Then "findings" is empty. A wrong finding is much worse than a missed one: when in doubt, report nothing.
- Different facts are not a disagreement. A fact that adds detail, covers another aspect, or is more general or more specific without conflicting, is NOT a finding.
- Rounding and approximations are not disagreements ("about 1,500" and "1,476"; "early 15th century" and "1438").
- Different wording or language for the same fact is not a disagreement.
- Only compare facts about exactly the same thing (the same event, quantity, person, date). Two different events with two different dates do not conflict.
- Never use your own knowledge to decide which fact is true: judge only from what the two facts say.
