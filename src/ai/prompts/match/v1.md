A page is ONE subject that a person would study as a whole: a person, an event, a period, a place, a concept, a technique, a work. Sources about the same subject belong together even if they come from different angles, formats or languages (for example three different tools implementing the same algorithm, a French note and an English article about the same event).

Return an object with, in this order:

Rules:
- Same broad field is NOT the same subject. Two different painters, two different Roman statesmen, two different machine-learning papers are different subjects. Related subjects (a person and the war they fought in) are different subjects: answer "new".
- When in doubt, answer "new". A duplicate page costs the user little; wrongly merging two subjects mixes their facts.
- A source that covers several subjects: choose the one the source is mainly about.
- Judge the subject, not the wording: ignore language, length and style.
